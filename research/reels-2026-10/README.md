# Исследование рилзов @harsh.times — октябрь 2026

Всё в одной папке: данные, транскрипты, разметка, код, результаты, отчёты, локальный пайплайн.

## Структура

| Папка | Что внутри |
|---|---|
| `data/` | `reels_stats_2026-10-12.csv` — статистика всех 83 рилзов из Apify; `labels_2026-10-12.csv` — ручная разметка 62 хитов (>10K): тема, архетип хука, период; `transcripts_full_2026-10-12.json` — **полные транскрипты 63 роликов** (заново не транскрибировать); `transcripts/` — хуки и выдержки; `EXCLUDED.md` — исключённые |
| `annotations/` | `CODEBOOK.md` — правила разметки (v1 → v2 → v3 → v4, история правок после калибровок); `sentences_<code>.json` — фразы; `labels_<code>.json` — эмоции v2 + функции v3 + блок story v3; **`story_v4/<code>.json` — актуальные сюжетные метки** (template, conflict, stakes, pov) после калибровки с Аделем; `frames_v1/<code>.json` — визуальный слой по кадрам (лицо, экран, девайс, плашка, формат) для всех 83; `v1/`, `v2/` — старые версии; `calibration_adel*.jsonl` — ответы Аделя для сверки; `excluded/` |
| `code/` | скрипты анализа, запускать из любого места: `python3 code/<script>.py` |
| `results/` | выходы скриптов (`*_2026-10-13.txt` — актуальные, без Dc-27MTgu47) |
| `reports/` | отчёты с выводами и их статусом |
| `local/` | пайплайн локального запуска (**прогнан 2026-10-13**): видео, голос, кадры, HF-модели, эмбеддинги. Выходы в `local/outputs/`: таймкоды фраз, просодия, эмоция голоса, склейки и кадры, транскрипты провалов. Видео и аудио не в git |
| `retention/` | сюда класть скриншоты кривых удержания `<code>.png` |

## Методология, по шагам

1. **Выгрузка** (Apify `instagram-reel-scraper`): 83 рилза, статистика + транскрипты для 63 с >10K. Корпус хитов, провалы не анализировались по решению Аделя.
2. **Статистика по факторам** (`code/analyze.py`): медианы по теме, хуку, длительности, периоду. → `reports/`-нет, выводы в `skills/tov-adel-reels/` и `results/analyze_*.txt`.
3. **Морфология** (`code/morphology.py`, pymorphy3): части речи, лицо, время, повелительное наклонение в хуке и теле vs просмотры. Связи слабые.
4. **Психоэмоциональная разметка фраз** (`annotations/CODEBOOK.md`): valence, arousal, эмоция зрителя, функция фразы, открытая интрига, приём. Разметчики — 4 LLM-агента вслепую (не видят просмотров).
   - v1 → калибровка с Аделем по 12 фразам: 6/12 совпадений, LLM ставила негатив там, где зритель чувствует любопытство → `reports/emotion-calibration-2026-10.md`.
   - v2 (правило «эмоция зрителя, а не тон события»): 10/12.
   - калибровка функций фраз: 6/12 → правила v3 (нет «вводной», поворот = любое противоречие ожиданию, инсайт = факт с выводом, обещание = названо что получит зритель) → **11/12**.
5. **Сводка эмоций vs метрики** (`code/emotion_analyze.py`) → `reports/emotion-analysis-2026-10.md`.
6. **Проверка с контролем факторов** (`code/reel_features.py`, `code/multivariate.py`): тема, период, длительность, код в комменты, для вовлечённости ещё просмотры; перестановочный тест; leave-one-out → `reports/multivariate-structure-2026-10.md`. Здесь отвалился вывод «хук через идентичность» (это была тема-манифест).
7. **Сторителлинг v3** (`code/story_analyze.py`): шаблон, конфликт, ставки, герой, Фрейтаг, круг Хармона → `reports/storytelling-analysis-2026-10.md`. **Устарел**: см. шаг 9.
8. **Локальный пайплайн** (`local/README.md`): таймкоды (whisper large-v3), HF-эмоции текста и голоса, эмбеддинги, просодия, склейки и кадры. Прогнан 2026-10-13 → `code/multivariate_local.py`, `reports/local-pipeline-2026-10.md`.
9. **Калибровка story-меток с Аделем** (12 роликов, `annotations/calibration_adel_story.jsonl`): v3 совпала 5/12 по каждому полю. Кодбук v4: формы без листикла и девлога, спор без tool_vs_tool, ставки без fomo и с knowledge, «герой» заменён на «призму» (pov). Переразметка вслепую → `annotations/story_v4/`, совпадение 12/11/10/12 из 12. `code/story_analyze_v4.py` → `reports/storytelling-v4-2026-10.md`.
10. **Семантика текста и подписи** (`code/semantics.py`, `code/captions.py`) → `reports/semantics-captions-2026-10.md`.
11. **Провалы <10K** (13 роликов, транскрипция whisper, `code/fails.py`) → `reports/fails-2026-10.md`.
12. **Речевые обороты и сценарные приёмы** (`code/devices.py`): 20 оборотов по регуляркам, позиция в ролике, накал, функция, метрики; тема × форма × хук → `reports/devices-2026-10.md`.
13. **Проверка на прочность** (`reports/robustness-2026-10.md`): пересчёт без трёх закреплённых роликов (`REELS_EXCLUDE=…`, `results/nopin/`), подача голосом по фразам (`code/prosody_phrases.py`), перепосты (`code/reposts.py`), визуальный слой по кадрам (`code/frames_analyze.py`, `annotations/frames_v1/`).

## Статус выводов (n=60 хитов, разметка story v4; 2026-10-13)

| Вывод | Статус |
|---|---|
| 45–60 с — оптимум длительности; провалы короче (52 с против 72 с, p=0.012) | данные, две выгрузки + провалы |
| Манифест «если бы я был новичком в N году» — лучший каркас (до 436K) | данные |
| Нет ставки для зрителя (время, деньги, работа, знание) → ÷2.5 просмотров | данные, p=0.046 (v3: p=0.055) |
| Своя история без пути повторить (`case_story`) → ÷2 просмотров | данные, p=0.040 |
| Обещание в строгом смысле → ×1.8 просмотров | данные, p=0.039, держится в v3 и v4 |
| Призма зрителя («ты тоже так можешь») → больше лайков; своя ситуация → меньше | данные, p=0.018 / 0.011 (бывший «герой-автор») |
| Враг в ролике (на уровне фраз) → ×6 комментов на просмотр | данные, p=0.008 |
| Инструкция → меньше комментов, инсайт → больше | данные, p<0.001 / 0.04, держится в v4 |
| Третье лицо и ставка «знание» (эссе) → ×8–11 комментов на просмотр | данные, p≤0.001, но это 8 роликов |
| Слова про время в тексте → больше просмотров | данные, p=0.009 |
| Широкий диапазон голоса → больше просмотров | данные, p=0.014 |
| Быстрая речь → меньше комментов | данные, p=0.002 |
| Угроза самому зрителю → меньше просмотров | данные, p=0.025, несут 16 роликов |
| Одна интрига лучше нескольких | слабо, p 0.05–0.1 |
| Меньше склеек → больше просмотров; больше и раньше склейки → больше комментов | гипотеза, p 0.02–0.06 |
| Ставка-время лучше ставки-деньги | ❌ не различимы в v4 (обе положительны, p>0.15) |
| Конфликт «инструмент против инструмента» → ×3.4 | ❌ снят: Адель такой категории не видит, в v4 её нет |
| Листикл вне манифеста → ÷2.9 | ❌ снят как формулировка: листикла как формы нет; содержательно → «case_story ÷2» |
| Хук через «для кого» / врага сильнее контраста | ❌ снят (тема-манифест) |
| Вторая фраза — действие | ❌ снят после переразметки v3 |
| Форма эмоциональной дуги | ❌ снят |
| Подписи к роликам | не подтверждено (все p>0.4 на просмотры и комменты) |
| Эмоция голоса (HF RESD) | не измерено: модель выдаёт константу |
| Круг Хармона, пирамида Фрейтага | не подтверждено по таймкодам; нужно удержание |
| **Без лица автора ролик не летит**: провалы 0 из 5 кадров с лицом, хиты 4 из 5 | данные, n=13 провалов |
| Запись экрана как второй слой (talk_screen) — слабейший формат, 23K против 51–64K | данные, p=0.054 с контролем |
| Чистый talking head = смерть | ❌ не подтверждено по кадрам: 38K, не хуже среднего |
| Пик ролика — контраст с двумя цифрами; антитеза «не X, а Y» — приём тела, не хука, ни на что не влияет | данные (уровень фраз) |
| Нумерация «первое, второе» в речи режет комменты | данные, p=0.019 |
| Подача голосом ровная: поворот и инсайт голосом не выделяются; выделяется только хук | данные (просодия по фразам) |
| Перепост слово в слово теряет 70–85%; тот же каркас с новым телом не выгорает | данные, 2 группы |
| Длинная первая фраза, меньше склеек → просмотры | ❌ сняты: эффект одного закреплённого ролика |
| Нет ставки → ÷2.5; своя история без пути повторить → ÷2 | данные на грани: без трёх закреплённых p=0.056 / 0.096 |

Около 400 тестов в сумме, случайно значимы 15–20; три верхних ролика закреплены в профиле (проверка без них — `reports/robustness-2026-10.md`); доверять p≤0.01 и повторам в разных метриках и версиях разметки. Все выводы — для одного аккаунта и только по хитам.
