# Реальные рилзы Аделя с разбором

Это 10 живых рилзов из аккаунта `@harsh.times` (2025-2026). Каждый разобран по схеме: **HOOK → SETUP → BODY → CLOSE → CTA + визуальный слой + что в успехе/провале — тема, что — формат, что — ToV**. Возвращайся к этим примерам, когда пишешь сценарий — здесь голос и форма видны лучше любого правила.

**Подбор примеров**:
- 3 топ-перформера (≥100K views) — что точно работает
- 2 средних кейса (40-80K views) — рабочий стандарт
- 1 мем-эксперимент (~80K на n=1) — особая категория
- 1 кинематографичный кейс (50K) — другой формат
- 3 флопа (<5K views) — что точно не работает и почему

## Пример 11. Открытая петля + контр-тезис из своей же ниши (новый, 2026-05)

Этот рилс — **новый образец для подражания**, не из аналитики корпуса (его ещё нет в опубликованных), а из совместной работы автор+Claude. Показывает **редкий приём: контр-тезис против своей же ниши** (AI-эксперт ругает ИИ) + **open-loop структура** (обещание фикса в начале → выдача в финале).

**Тема**: ai_tools + counter-thesis | **Формат**: cinematic_promo + screencast | **Длительность цели**: 65–70s

### Скрипт

```
[HOOK]
ИИ создан не для того, чтобы ты умнел, 
а для того, чтобы ты платил подписку.

[SETUP + МОСТ К ФИНАЛУ]
Поэтому это настоящий подхалим манипулятор и социопат, 
который заставит тебя поверить в то, чего нет в действительности. 
Если используешь его для одной из этих задач — плохие новости. 
В финале дам фразу, которая его лечит.

[КЕЙС 1 — БИЗНЕС-ПРОЕКТЫ]
Оценка идеи проекта. 
Скажет, что твоя идея гениальная, рынок ждёт. 
Не потому что правда — а потому что ему важно, чтобы ты не закрыл чат. 
Принесёшь полный отстой — а ИИ будет пищать как школьница 
перед старшеклассником.

[КЕЙС 2 — ПСИХОЛОГ]
Консультация с психологом? 
ИИ либо доведёт тебя до шизофрении, найдя несуществующие симптомы. 
Либо убедит, что ты — непризнанный гений, 
которого не принимает окружение.

[КЕЙС 3 — РЕБЁНОК]
Воспитание ребёнка. 
ИИ даст советы в духе американских фильмов, 
где папа непременно называет сына чемпионом, 
наплевав на реальные обстоятельства. 
Каждый ребёнок уникален — и важно, чтобы уникальными были родители. 
Просто работать по шаблонам — офигенный путь к травмированию.

[ГАЙД-ФИКС — закрытие open-loop]
Лечится одной фразой. Ставишь её в начало любого важного запроса:
«Не подыгрывай. Найди три контраргумента и один кейс, 
где такой подход провалился.»
Дальше ИИ работает на тебя, а не против.

[CLOSE]
Скопируй из первого коммента. До связи.
```

### Что делает этот рилс показательным

| Приём | Где сработал |
|---|---|
| **Двухтактный хук с антитезой-раскачкой** | «не для того, чтобы X, а для того, чтобы Y» — длинно, но даёт нарастание давления |
| **Триплет-приговор без запятых** | «подхалим манипулятор и социопат» — читается как одно слово |
| **Описательная фраза-удар** | «заставит тебя поверить в то, чего нет в действительности» — главная сила сетапа |
| **Угроза перед перечислением** | «у меня для тебя плохие новости» — провоцирует досмотр |
| **Open-loop в setup** | Обещание «в финале дам фразу» = крючок на 50+ секунд |
| **Контр-тезис из своей ниши** | AI-консультант ругает AI = неожиданно, виральный сигнал |
| **Метафоры из социальных сцен** | «пищать как школьница», «папа называет сына чемпионом» — узнаваемая образность вместо абстракции |
| **Финал = практический гайд** | Фраза-фикс крупно на экране 4+ сек = saves-механика |
| **CTA «скопируй из первого коммента»** | Конкретное действие + закреплённый коммент с фразой = высокие saves |

### Что в этом рилсе — собственно ToV-уроки

1. **«Не для того, чтобы X, а для того, чтобы Y»** — не сокращать в «не делает X, делает Y». Раскачка — это не баг, это feature.
2. **Триплет без запятых** — это устная плотность. Запятые ставит редактор, не автор.
3. **«У меня для тебя плохие новости»** — рабочий мостик-угроза перед списком.
4. **«ИИ будет пищать как школьница»** — метафора из социальной сцены, не из абстракции. Так Адель делает образность.
5. **«Каждый ребёнок уникален — и важно, чтобы уникальными были родители»** — типичная структура «параллельные слова с переворотом». Сильнее, чем «нужен индивидуальный подход».

### История создания (важно для понимания процесса)

Этот рилс — **итог итераций автор↔Claude**. Начальный черновик автора имел whisper-баги и заголовки кейсов без тел. Claude сначала **переборщил с правкой** (выкинул сильные описательные фразы, заменил образное на корпоративный жаргон «KPI длина диалога»). После личного фидбэка автора:
- Восстановлены оригинальные фразы хука и сетапа
- Тела кейсов 1, 2, 3 написаны автором с образными метафорами
- Claude добавил: структуру (open-loop), порядок кейсов, гайд-блок, визуальные инструкции

**Урок**: финальная сила рилса = **авторский голос + структурная гигиена**. Не одно вместо другого.

## Итоги по 10 примерам

**Что работает (подтверждено топ-кейсами)**:
1. Конкретный девайс / собственный продукт / манифест как тема
2. Длительность 45-60s
3. Cinematic_promo с тяжёлым screencast/b-roll слоем
4. Цифровая плотность речи (3+ конкретные цифры в 60 сек)
5. Двухтактный хук с цифрой в первой фразе
6. Caption-вопрос (короткий) + расширение в caption
7. CTA «до связи» как сигнатура

**Что не работает (подтверждено флопами)**:
1. Lifestyle / family как **тема ролика** (как штрих — допустимо)
2. Внешние данные (McKinsey, исследования) без личного кейса
3. Длительность 90+ секунд
4. Хук без цифры/конкретики (для не-мемов)
5. Пустой контент с минимумом приёмов

**Что неясно (малая выборка)**:
1. Мемы — n=1 хит, нужно больше экспериментов
2. Чисто question-хуки — n=3, сильный разброс (146K → 4K)
3. Серии «День N» — пока две точки, нужно больше

## Финальное правило по примерам

Когда пишешь сценарий, ищи **прямой аналог** среди этих 10 примеров. Если твой рилс ближе всего к DTSpC0DEodJ — копируй структуру (девайс в руках + цифра + кейсы применения + название в конце). Если ближе к DPlIdjdEhTm — копируй структуру манифеста (формула «Если бы я был» + пункты с антитезой + soft CTA в последнем пункте). Если ни на что не похоже — **сомневайся**, действительно ли это тема для этого аккаунта.
